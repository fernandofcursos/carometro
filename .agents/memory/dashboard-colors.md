---
name: Dashboard Color System
description: Color scheme used for navigation icons, stat cards, and user avatars in dashboard.
---

Each navigation item and stat card has a dedicated color:
- Dashboard/Primary: `#6366f1` (indigo)
- Analytics/Success: `#10b981` (emerald)
- Users/Warning: `#f59e0b` (amber)
- Alerts/Danger: `#ef4444` (red)
- Settings/Neutral: `#64748b` (slate)

**Why:** Each section gets a distinct identity color that makes the UI feel alive and helps users associate sections with colors.
**How to apply:** When adding new menu items or stats, assign a color from the palette. Keep the bgColor at ~10% opacity (light tint) for the icon backgrounds.
